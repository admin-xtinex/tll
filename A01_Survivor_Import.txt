A01 Survivor rigged base
Unity 6 URP import

Files

  A01_Survivor_RiggedBase.glb   same mesh for glTF tools.
  T_A01_Survivor_*_PC.png       2048. Assign these on the Windows material.

Scale and axis
  1 unit = 1 meter. Height 1.80 m. Feet on Y=0 in Unity (Z=0 in Blender).

  Bind pose is an A-pose. Rig type in Unity: Humanoid.
